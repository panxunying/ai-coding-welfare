## Getting started

1. Follow the full referral link and check the registration requirements and reward conditions.
2. Create a key in the dashboard. Use the verified endpoint below, or obtain the current endpoint from the provider if none is public.
3. Configure a supported client, try a small request and check actual balance consumption before relying on the service.

## Safety and disclosure

- Links may contain referral codes. Rewards and eligibility are set by each provider; signup alone does not guarantee a reward.
- This is an independent directory, not a service operator or a guarantee of uptime. Free offers, prices and policies can change or disappear.
- Do not send production secrets, private data or company code to unknown gateways. Use official APIs for important work.
- Follow provider and upstream terms. Do not mass-register accounts, abuse promotions or resell credits.
- Issue submissions are posted by community members and may be unverified. Assess them independently before registering.

## Contributing and translations

Edit data/sites.json for shared facts and data/locales/*.json for translated copy, then run npm test and npm run build. README files and HTML pages are generated; do not edit them directly. Report translation errors through Issues.

## Why these languages?

GitHub does not publish an official ranking of human languages. This project uses the developer-population geography in Octoverse 2025 as a coverage proxy: English, Hindi, Brazilian Portuguese, Japanese and German, in addition to existing Chinese. Country is not language; India is multilingual and Hindi does not represent all Indian developers.
