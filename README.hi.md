पहले दिन के क्रेडिट = पंजीकरण + रेफ़रल + पहला चेक-इन (या एक दिन का कोटा)। ये अलग-अलग सेवाओं के बैलेंस हैं, नकद नहीं। अंक, साइट इकाइयाँ, सशुल्क प्लान, संग्रहित सेवाएँ और बंद पंजीकरण USD कुल में शामिल नहीं हैं। शर्तें और वास्तविक क्रेडिट अलग हो सकते हैं।

क्रेडिट नियम प्रदाता की घोषणाओं से मैन्युअल रूप से दर्ज होते हैं; सार्वजनिक API हमेशा इन्हें नहीं बताती। जहाँ अनुमति है, मॉडल, कीमतें और पहुँच की स्थिति अपने-आप अपडेट होती है। पहुँच योग्य होने से सफल पंजीकरण या मॉडल उपयोग सिद्ध नहीं होता।

## शुरुआत कैसे करें

1. पूरा रेफ़रल लिंक खोलें और पंजीकरण व पुरस्कार की शर्तें पढ़ें।
2. डैशबोर्ड में कुंजी बनाएँ। नीचे दिया सत्यापित endpoint इस्तेमाल करें, या सार्वजनिक न होने पर प्रदाता से मौजूदा पता लें।
3. समर्थित क्लाइंट सेट करें, छोटा अनुरोध भेजें और सेवा पर निर्भर होने से पहले वास्तविक बैलेंस कटौती जाँचें।
