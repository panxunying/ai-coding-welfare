As regras de crédito são registradas manualmente a partir de comunicados; as APIs públicas nem sempre as expõem. Modelos, preços e acessibilidade são atualizados automaticamente quando permitido. Um site acessível não comprova cadastro bem-sucedido nem acesso aos modelos.

Requisitos de cadastro

Use o link de indicação com GitHub ou LinuxDO. Saia e entre novamente se os créditos não aparecerem.

Recompensas, limites e cuidados importantes

Faça check-in no painel; eventos e indicações podem render mais créditos. Sem promessa de SLA ou recargas. O conteúdo das requisições é restrito a chinês, inglês, francês, alemão e russo: prompts em português, hindi ou japonês podem retornar HTTP 400. Esta tradução do diretório não altera essa restrição. Contas em massa, abuso e indicações falsas podem causar banimento.

Configuração do cliente

Crie uma chave de API no painel e use apenas um modelo disponível para sua conta. URLs base Anthropic não incluem /v1; as compatíveis com OpenAI geralmente incluem. Um endpoint de protocolo não garante suporte a todos os modelos ou clientes.

Segurança e transparência

  • Os links podem conter códigos de indicação. Cada provedor define recompensas e elegibilidade; cadastrar-se não garante uma recompensa.
  • Este é um diretório independente, não um operador nem uma garantia de disponibilidade. Ofertas gratuitas, preços e regras podem mudar ou desaparecer.
  • Não envie segredos de produção, dados privados ou código de empresas a gateways desconhecidos. Use APIs oficiais para tarefas importantes.
  • Respeite os termos dos provedores e dos serviços de origem. Não crie contas em massa, abuse de promoções ou revenda créditos.
  • As sugestões nas Issues são publicadas pela comunidade e podem não estar verificadas. Avalie-as antes de se cadastrar.
