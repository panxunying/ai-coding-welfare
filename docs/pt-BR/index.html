Visão geral

Crédito no primeiro dia = cadastro + indicação + primeiro check-in (ou uma cota diária). São saldos separados em cada serviço, não dinheiro. Pontos, unidades internas, planos pagos, serviços arquivados e cadastros fechados ficam fora do total em USD. Condições e créditos recebidos podem variar.

As regras de crédito são registradas manualmente a partir de comunicados; as APIs públicas nem sempre as expõem. Modelos, preços e acessibilidade são atualizados automaticamente quando permitido. Um site acessível não comprova cadastro bem-sucedido nem acesso aos modelos.

Primeiros passos

  1. Acesse o link de indicação completo e confira os requisitos de cadastro e as condições das recompensas.
  2. Crie uma chave no painel. Use o endpoint verificado abaixo ou obtenha o endereço atual com o provedor se não houver um público.
  3. Configure um cliente compatível, faça uma requisição pequena e confira o consumo real do saldo antes de depender do serviço.

Contribuições e traduções

Edite data/sites.json para fatos compartilhados e data/locales/*.json para traduções; depois execute npm test e npm run build. Os arquivos README e as páginas HTML são gerados: não os edite diretamente. Relate erros de tradução pelas Issues.

Por que estes idiomas?

O GitHub não publica um ranking oficial de idiomas naturais. Este projeto usa a distribuição geográfica de desenvolvedores do Octoverse 2025 como aproximação de alcance: inglês, hindi, português brasileiro, japonês e alemão, além do chinês já existente. País não equivale a idioma; a Índia é multilíngue e o hindi não representa todos os desenvolvedores indianos.

Segurança e transparência

  • Os links podem conter códigos de indicação. Cada provedor define recompensas e elegibilidade; cadastrar-se não garante uma recompensa.
  • Este é um diretório independente, não um operador nem uma garantia de disponibilidade. Ofertas gratuitas, preços e regras podem mudar ou desaparecer.
  • Não envie segredos de produção, dados privados ou código de empresas a gateways desconhecidos. Use APIs oficiais para tarefas importantes.
  • Respeite os termos dos provedores e dos serviços de origem. Não crie contas em massa, abuse de promoções ou revenda créditos.
  • As sugestões nas Issues são publicadas pela comunidade e podem não estar verificadas. Avalie-as antes de se cadastrar.
