利用を始めるには

  1. 完全な紹介 URL を開き、登録条件と特典条件を確認します。
  2. 管理画面でキーを作成します。以下の確認済みエンドポイントを使うか、非公開の場合は提供元から最新の URL を取得します。
  3. 対応クライアントを設定して少量のリクエストを試し、実際の残高消費を確認してから利用してください。

言語の選定について

GitHub は自然言語の公式人気順位を公開していません。本プロジェクトでは Octoverse 2025 の開発者の地域分布を参考に、既存の中国語に加え、英語、ヒンディー語、ブラジルポルトガル語、日本語、ドイツ語を選びました。国と言語は同一ではなく、多言語国家のインドの開発者全員をヒンディー語で代表することはできません。

安全性と開示事項

  • リンクには紹介コードが含まれる場合があります。特典と対象条件は各提供元が定めており、登録だけでの特典付与は保証されません。
  • 当サイトは独立した情報一覧であり、サービス運営者でも稼働保証者でもありません。無料特典、料金、規約は変更・終了される場合があります。
  • 不明なゲートウェイに本番用の秘密情報、個人データ、会社のコードを送らないでください。重要な用途には公式 API を使ってください。
  • 各サービスと上流提供元の規約を守ってください。大量登録、特典の不正利用、クレジットの転売は禁止です。
  • Issue は利用者による投稿で、未検証の内容もあります。登録前にご自身で判断してください。
